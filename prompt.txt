Let's create a python game publishing system for programming students. Create an html file that runs the python code in game.py and game2.py. The user must be able to select which game to play, restart the game and look at the source code. The games will be text adventure games that must be able to use the "input" procedure to ask input from the user and print text on the screen. There will be more python files and it should be easy to recreate the html file to run those. It should also be possible to later write games that draw graphics on the screen and accept mouse events and key press events instead of reading text commands.
